# 安装与使用

## 环境

- Android 15 / ColorOS 15
- 已安装并正常工作的 Magisk/KernelSU 与 LSPosed
- 小布助手 11.8.3，包名 `com.heytap.speechassist`

## 安装

1. 安装 `BreenoTTSHook-debug.apk`。
2. 在 LSPosed 中启用 BreenoTTSHook。
3. 模块作用域只勾选“小布助手 / `com.heytap.speechassist`”，不要勾选系统框架或无关应用。
4. 强制停止并重新启动小布助手；必要时重启设备。
5. 打开 BreenoTTSHook APP，确认 API 地址并点击“刷新音色”和“测试连接”。
6. 选择角色/情感，或开启“使用手动音色”直接填写值；点击“试听”。
7. 开启“启用第三方 TTS”并保存。配置版本增加后，Hook 进程会读取同一份配置。

## 回退与调试开关

- “失败时使用原 TTS”：仅在第三方尚未输出首个 PCM 时恢复本次原 WebSocket 发送。
- “严格调试模式”：发生错误时禁止原 TTS 回退，便于暴露兼容问题。
- “强制模块播放器”：预留给原播放器兼容调试；当前未验证原播放器时实际使用 `AudioTrack`。
- 日志级别可选 `ERROR / INFO / DEBUG`，但不会记录完整播报文本。

## 安全停用/恢复

如果小布异常、无声或崩溃：

1. 在 LSPosed 中取消模块作用域并强制停止小布。
2. 重新启动小布，确认原 TTS 恢复。
3. 再打开模块 APP，关闭“启用第三方 TTS”，或恢复默认配置。
4. 收集诊断后再重新启用。模块不修改小布 APK，停用 LSPosed 作用域即可恢复。

## HTTP 提醒

`http://47.111.184.220:5000/` 是未加密连接。不要用真实隐私文本做测试；连接测试固定使用“你好，这是连接测试。”。建议配置 HTTPS 服务。
