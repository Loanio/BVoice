# 诊断说明

## 查看日志

模块 App 和小布内嵌设置页均可显示当前配置状态、连接检查结果和最近诊断记录。设置页底部的“复制诊断日志”可将记录复制到剪贴板。

日志等级默认 `ERROR`，可在高级设置中调整为 `INFO` 或 `DEBUG`。

## 常见状态

| 状态 | 含义 |
| --- | --- |
| `active` | TTS 路由已安装 |
| `intercepted` | 已接收一次第三方 TTS 请求 |
| `playing` | 模块正在播放第三方音频 |
| `completed` | 当前播报已结束 |
| `failed` | 当前播报失败 |
| `cancelled` | 当前播报已取消 |
| `unsupported` | 当前目标不匹配已支持的 Hook 路由 |
| `disabled` | 第三方 TTS 未启用 |

## 排查建议

- 确认 LSPosed 作用域仅包含 `com.heytap.speechassist`，并在修改后重启小布助手。
- 确认服务地址可访问，角色与情感目录能够加载，试听可以播放。
- 检查“启用第三方 TTS”和“失败时使用原 TTS”的设置。
- 使用 HTTPS 或可信局域网服务，避免在 HTTP 连接中发送敏感文本。

## 隐私

诊断记录使用字符数和摘要标识播报内容，不包含完整播报文本、Cookie、Token 或完整请求体。反馈问题前请检查日志中是否含有服务地址或其他私人信息。
